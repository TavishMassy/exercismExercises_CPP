These exercises range from basic syntax familiarization to advanced algorithms and C++ specific paradigms. This repository serves as a personal milestone and a reference for solving algorithmic problems, memory management, and object-oriented design in modern C++.

## 🧠 Core Concepts Covered

Throughout these 100 exercises, I explored and implemented a wide variety of C++ features and computer science concepts, including:

* **Object-Oriented Programming (OOP):** Classes, structs, namespaces, and operator overloading (`clock`, `complex-numbers`).
* **Memory Management:** Raw pointers, smart pointers (`unique_ptr`, `shared_ptr`), and manual memory allocation (`simple-linked-list`, `power-of-troy`, `binary-search-tree`).
* **Standard Template Library (STL):** Extensive use of vectors, maps, unordered maps/sets, strings, and standard algorithms (`parallel-letter-frequency`, `robot-name`).
* **Advanced C++ Features:** Templates, lambda functions, argument-dependent lookup, and exception handling/error throwing (`list-ops`, `sublist`, `bank-account`).
* **Algorithms & Data Structures:** Binary Search Trees, Linked Lists, Circular Buffers, Dynamic Programming (`knapsack`), recursion, matrices, and various ciphers.
* **Concurrency:** Multithreading and concurrent memory access (`bank-account`, `parallel-letter-frequency`).

## 📁 Repository Structure

Each folder corresponds to a specific Exercism problem and is numbered in the order of completion (from `00` to `99`). Inside each folder, you will typically find:
- The `.cpp` and `.h` files containing the solution.
- A `README.md` file containing the original problem description provided by Exercism.
